Transforming countries' Loan Landscape with AI

Kenya like any other country faces a growing challenge with non-performing loans (NPLs). With economic uncertainty and poor financial planning, borrowers struggle to repay debts while lenders grapple with risk assessment. Our solution bridges this gap using artificial intelligence.

This project leverages Google's Gemini 1.5 Flash to create an intelligent system that analyzes financial documents, assesses credit risk, and delivers personalized loan advice—powered by real-world M-Pesa transaction data.

The Problem

Recent financial report from KCB bank kenya showed an increased NPL which may be as a result of:

  • Surging default rates due to economic volatility
  • Limited tools for accurate risk assessment
  • Borrowers lacking access to tailored guidance

How the System Works

Gemini's 10M+ token context window ingests Kenya's Financial Performance Documents, extracting key insights for tailored advice based on sector of the bussiness:
